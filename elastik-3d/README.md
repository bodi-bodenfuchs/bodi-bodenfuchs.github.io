# Bodi 3D-Baukasten – Elastische Bodenbeläge

Interaktive 3D-Übungen zum Skriptum „Elastische Beläge“ (Heft 1 Material, Heft 2 Verlegung)
für den Lehrberuf Bodenleger/in.

- `index.html` – Elastische Beläge: Bauen, Erkunden, Benennen, Herstellung, Fliesen aufteilen
- `parkett/index.html` – Parkett im Schichtaufbau (für das Holz-Skriptum)

## Veröffentlichen mit GitHub Pages

1. Neues Repository anlegen (z. B. `bodi-3d-baukasten`), öffentlich.
2. Alle Dateien dieses Ordners hochladen („Add file → Upload files“).
3. Settings → Pages → Source: „Deploy from a branch“, Branch `main`, Ordner `/ (root)` → Save.
4. Nach ca. 1 Minute ist die Seite erreichbar unter https://bodi-bodenfuchs.github.io/elastik-3d/.

Die Seite lädt three.js von cdnjs bzw. jsdelivr – eine Internetverbindung ist nötig.
